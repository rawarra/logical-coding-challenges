💻 **Today’s Learning: Converting Decimal Numbers to Binary**

Today, I learned a simple shortcut method to convert **decimal numbers into binary numbers**.

### 🔢 How the Shortcut Works — Example: 20

First, write the binary place values:

**64 | 32 | 16 | 8 | 4 | 2 | 1**

1️⃣ Find the largest value that fits into 20.
The largest value is **16**, so write **1**.
20 − 16 = **4**

2️⃣ Move to **8**.
8 does not fit into 4, so write **0**.

3️⃣ Move to **4**.
4 fits into 4, so write **1**.
4 − 4 = **0**

4️⃣ We have reached 0, so fill the remaining places with **0**.

So:

**64 | 32 | 16 | 8 | 4 | 2 | 1**
**0  |  0  |  1  | 0 | 1 | 0 | 0**

Therefore, **20 in binary = 10100**. ✅

### 🔄 Why I Used a `while` Loop

I used a **while loop** because we don't know in advance how many steps will be needed.

The number of steps depends on the number we enter:

🔹 A small number like **5** needs only a few steps.
🔹 A larger number like **132** needs more steps.

A `while` loop is useful because it tells the computer:

> **“Keep checking and processing until the value reaches 0, no matter how many steps it takes.”**

This was a simple concept, but understanding the logic behind it helped me improve my problem-solving skills. 🚀
